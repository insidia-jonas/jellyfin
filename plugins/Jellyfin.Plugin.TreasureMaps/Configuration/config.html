Languages

Releases are sorted by audio language: the primary language first, then your accepted secondary languages. Use ISO codes (de, en, es) or names (German).

AI recommendations (For You)

Powers the For You category in the channel: your watch/favorite history is sent to the chosen AI provider, which recommends matching movies & shows that are then looked up on the indexer.
Your key for the selected provider.
Empty uses the default: grok-3-mini / gpt-4o-mini / claude-3-5-haiku-latest.
For OpenAI-compatible gateways (OpenRouter, local LLMs, ...). Empty uses the provider's official endpoint.

Ratings (xREL)

Enrich releases with xREL ratings, matched by the release/scene name. Adds the scene video/audio rating (and the title rating) to each card.
Defaults to https://api.xrel.to/v2. These endpoints are public (no key required).

Subtitles (OpenSubtitles)

Adds an OpenSubtitles subtitle provider. It matches by exact file hash first, then IMDb id / title, in your chosen languages. Register a free API key at opensubtitles.com (Consumers). Downloading subtitles requires your account login.
From opensubtitles.com → Consumers.
Required to download subtitles.
Required to download subtitles.
