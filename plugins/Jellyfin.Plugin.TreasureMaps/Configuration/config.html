Treasure-Maps

Connect Jellyfin to your Treasure-Maps indexer. Enter the server address and your API key, then browse movie releases from the Treasure-Maps channel on the home screen.

The Treasure-Maps server address, e.g. https://treasure-maps.example. The /api/v1 path is added automatically.
Sent as the X-API-Key header. Find it in your Treasure-Maps account settings.
